# Walmart Reward Offer landing page

A static, responsive landing page for an independent promotional offer. It uses the supplied Walmart logo and affiliate URL. The page discloses that the offer is third party and does not claim a guaranteed reward or Walmart endorsement.

Offer ID 1157 describes a $750 Walmart reward for eligible U.S. participants aged 18 or older. The provider lists a survey, registration, 20 sponsored deals, and ID verification as requirements. Review the live offer terms before promoting or participating; terms can change.

## Deploy with Vercel

1. In Vercel, choose **Add New → Project** and import `ESCAPETHEMATRI/walmart-gift-card-landing`.
2. Keep **Framework Preset** as **Other** and leave the build command empty.
3. Set the output directory to `.` (the repository root), then deploy.

The page is `index.html`, with `walmart-logo.png` alongside it.
